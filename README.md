## 这是什么 / What is this

Perlin Flowfield 是一个运行在浏览器里的「活着的画」。它把二维平面切成一张由 Perlin 噪声生成的「流场」，让数千个粒子顺着流场的指向运动，每帧用半透明背景叠加制造拖尾，最终得到丝缕般连绵的粒子轨迹。
Perlin Flowfield is a "living painting" that runs in the browser. It slices the 2D plane into a flow field generated by Perlin noise, lets thousands of particles ride along the field's directions, and fades each frame with a translucent background to produce trailing strokes — the result is a continuous, silky web of particle trails.

整个页面是**一个 HTML 文件**，没有任何外部库、框架或网络请求，离线也能完整运行。所有视觉都来自代码本身，不依赖图片素材。
The whole page is **a single HTML file** with no external libraries, frameworks, or network requests — it runs fully offline. All visuals come from the code itself; no image assets are needed.

## 核心特性 / Core features

- **大规模粒子系统**：默认 6500 颗，可在 500–15000 之间实时调节；粒子坐标存于 `Float32Array`，单帧开销极低。
  **Large particle system**: 6500 particles by default, adjustable live between 500–15000; positions live in a `Float32Array` for minimal per-frame cost.
- **自实现 3D Perlin 噪声**：经典 Ken Perlin「改进版」插值（fade 曲线 `t³(t(6t−15)+10)`），带可复现的**种子（seed）**，保证同一种子永远得到同一片流场。
  **Self-implemented 3D Perlin noise**: classic Ken Perlin "improved" interpolation (fade curve `t³(t(6t−15)+10)`) with a reproducible **seed**, so the same seed always yields the same field.
- **fBm 多倍频噪声**：一键切换「分形布朗运动」，把多组不同频率的噪声叠加（默认 4 个倍频），让流场细节更丰富、更自然。
  **fBm multi-octave noise**: toggle Fractal Brownian Motion with one click, summing several noise frequencies (4 octaves by default) for richer, more organic detail.
- **日落色调 + 色相漂移**：默认暖色日落调色板，可开启「色相随时间极缓慢旋转」，画面整体呼吸般变色。
  **Sunset palette + hue drift**: a warm sunset palette by default, with an optional "hue slowly rotates over time" mode for a breathing color shift.
- **9 项实时参数面板**：粒子数、流场缩放、流速、旋绕度、演化速度、轨迹长度、线宽、亮度、暗角，全部滑块即时生效。
  **9 live parameters**: particle count, field scale, speed, swirl, evolution rate, trail length, line width, brightness, vignette — all sliders apply instantly.
- **分享即见**：一键把当前所有参数编码进 URL 的 `#hash`，复制链接发给别人，对方打开就是同一幅画。
  **Shareable state**: one click encodes all current parameters into the URL `#hash`; send the link and the recipient opens the exact same image.
- **2× 超采样导出**：离线重算一遍粒子并 2 倍分辨率渲染，导出适合当壁纸 / 打印的高清 PNG。
  **2× supersampled export**: re-simulates particles offscreen at 2× resolution and exports a high-res PNG suited for wallpapers / printing.
- **影院式体验**：控制面板悬停即出、移开即隐；适配 `prefers-reduced-motion`（系统开了减弱动效时自动收敛）。
  **Cinema-style UX**: the control panel appears on hover and hides on leave; honors `prefers-reduced-motion` (auto-calms when the OS asks to reduce motion).

## 工作原理 / How it works

1. **噪声场**：以 `(x, y, t)` 为坐标采样 3D Perlin 噪声，得到该点的「角度」。
   **Noise field**: sample 3D Perlin noise at `(x, y, t)` to get an "angle" for that point.
2. **角度→方向**：角度乘以 `ANGLE_MULT`（默认 `4π`）得到粒子的运动方向。
   **Angle → direction**: multiply the angle by `ANGLE_MULT` (default `4π`) to get the particle's heading.
3. **粒子推进**：每帧每个粒子沿当前方向前进 `SPEED` 像素。
   **Advance**: each frame every particle moves `SPEED` pixels along its heading.
4. **拖尾**：每帧先用 `FADE_ALPHA` 透明度的背景色（径向渐变）覆盖画布，旧轨迹逐渐淡出，新轨迹留存，形成丝缕感。
   **Trail**: each frame paints a `FADE_ALPHA`-opacity background (radial gradient) over the canvas, fading old trails while keeping new ones — producing the silky look.
5. **演化**：`timeOffset` 随 `TIME_SPEED` 递增，使 z 轴（时间维）缓慢推进，流场整体缓慢变形；可关闭。
   **Evolution**: `timeOffset` grows with `TIME_SPEED`, slowly pushing the time axis so the whole field morphs; can be disabled.
6. **配色**：按角度把粒子分到若干色桶（bucket），默认日落色；开启色相漂移时每帧旋转色相。
   **Coloring**: particles are bucketed by angle into default sunset colors; hue drift rotates the buckets each frame when enabled.

> 直觉理解：把流场想象成一根根看不见的「风向标」，粒子是随风飘的尘埃，尘埃走过的路被一点点擦淡，于是风本身被画了出来。
> Intuition: think of the field as invisible weathervanes; particles are dust riding the wind, and the faintly-erased paths they leave behind paint the wind itself.

## 界面与交互 / UI & interaction

- **左侧参数面板**：默认收起，鼠标移到**屏幕上方区域**会平滑滑入；左上角的 `⟨` 折叠按钮可手动收起/展开。
  **Left parameter panel**: collapsed by default; moving the mouse to the **top area** slides it in; the `⟨` button at top-left collapses/expands it manually.
- **右上角动作按钮**：鼠标移到**右上热区**时浮现（暂停、fBm、色相、分享、2× 导出等）。
  **Top-right action buttons**: appear when the mouse enters the **top-right hot zone** (pause, fBm, hue, share, 2× export…).
- **鼠标移动**：实时在光标附近「揭示」控制元素，不需要精确点击。
  **Mouse move**: control elements are revealed near the cursor — no precise clicking required.
- **种子显示**：面板里有一行 `SEED #NNNNNN`，是当前流场的身份证；点「重新生成」会换一个新种子。
  **Seed display**: a `SEED #NNNNNN` line is the field's ID; "Regenerate" swaps in a new seed.

## 参数面板详解 / Parameter panel

面板里每个滑块都标注了「短键」（用于分享链接），范围与默认值如下：
Each slider shows a **short key** (used in share links). Ranges and defaults:

| 中文标签 / Label | 短键 / Key | 含义 / Meaning | 范围 / Range | 默认 / Default |
|---|---|---|---|---|
| 粒子数 / Particles | `p` | 同时存在的粒子数量 / number of live particles | 500 – 15000 | 6500 |
| 流场缩放 / Field scale | `ns` | 噪声采样空间频率，越大流场越密 / noise spatial frequency | 0.0005 – 0.008 | 0.0025 |
| 流速 / Speed | `sp` | 粒子每帧前进像素 / pixels advanced per frame | 0.3 – 4 | 1.5 |
| 旋绕度 / Swirl | `sw` | 角度放大系数（实际 `sw × π`）/ angle multiplier (`sw × π`) | 1 – 8 | 4 |
| 演化速度 / Evolution | `ev` | 时间维推进速度，0 即静止 / time-axis speed, 0 = static | 0 – 0.003 | 0.0006 |
| 轨迹长度 / Trail | `tr` | 拖尾保留程度（%）/ trail persistence (%) | 0 – 100 | 75 |
| 线宽 / Line width | `lw` | 轨迹线条宽度（px）/ stroke width (px) | 0.3 – 3 | 0.8 |
| 亮度 / Brightness | `br` | 粒子绘制不透明度 / particle opacity | 0.05 – 0.5 | 0.18 |
| 暗角 / Vignette | `vg` | 四周压暗程度（%）/ edge darkening (%) | 0 – 100 | 60 |

> 小技巧：想看「静止的瞬间美」，把 `演化速度` 调到 0、`轨迹长度` 调高，再按 `S` 存图。
> Tip: for a frozen moment of beauty, set `Evolution` to 0, raise `Trail`, then press `S` to save.

## 技术实现 / Technical implementation

- **渲染 / Rendering**: 原生 HTML5 Canvas 2D，无 WebGL 依赖，兼容性极好 / native HTML5 Canvas 2D, no WebGL dependency, excellent compatibility.
- **噪声 / Noise**: 自实现 `class PerlinNoise`（3D，种子化），配套 `fbm(...)` 多倍频叠加；`FBM_OCTAVES=4` / self-implemented seeded 3D `PerlinNoise` class plus `fbm(...)`; `FBM_OCTAVES=4`.
- **随机 / Random**: `SeededRandom`（LCG 线性同余），保证种子可复现 / LCG-based `SeededRandom` for reproducible seeds.
- **数据结构 / Data**: 粒子位置/速度用 `Float32Array` 存储，避免 GC 抖动 / particle pos/vel in `Float32Array` to avoid GC stutter.
- **背景 / Background**: 缓存的径向渐变（中心靛蓝 → 边缘近黑），叠加暗角遮罩层 / cached radial gradient (indigo center → near-black edge) plus a vignette overlay.
- **导出 / Export**: `savePNG()` 直接 `canvas.toDataURL`；`exportHiRes(2)` 在离屏画布以 2× 缩放重新模拟粒子后导出 / `savePNG()` uses `canvas.toDataURL`; `exportHiRes(2)` re-simulates at 2× on an offscreen canvas.
- **零依赖 / Zero deps**: 纯 Vanilla JavaScript，单文件、无构建步骤 / pure Vanilla JS, single file, no build step.
